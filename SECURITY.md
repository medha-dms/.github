# Security

Medha stores student marks and personal data, so security issues matter a lot.

## Report a problem

Please **do not** open a public issue for a security problem.

Use GitHub's **private vulnerability reporting** on the affected repository (Security tab → "Report a vulnerability"), or contact the organization owners directly.

Tell us:

- which repository and service
- what the problem is and how to reproduce it
- what data could be exposed

We will reply as soon as we can and fix the problem before it is made public.
